# Student Grade Calculator

## 📌 Project Overview

The **Student Grade Calculator** is a beginner-friendly Python project that calculates a student's grade based on the marks entered by the user. It validates the input, assigns a grade using conditional statements, and displays an encouraging message based on the student's performance.

This project was created as part of **Week 2: Making Decisions & Repeating Tasks in Python**.

---

## 🎯 Objectives

* Learn how to use **if-elif-else** statements.
* Practice **while loops** for input validation.
* Create and use **functions**.
* Handle invalid user input using **try-except**.
* Build a simple real-world Python application.

---

## 🛠️ Technologies Used

* Python 3

---

## ✨ Features

* Accepts student name and marks.
* Validates that marks are between **0 and 100**.
* Prevents invalid inputs (letters or symbols).
* Calculates grades using **if-elif-else** statements.
* Displays encouraging messages for each grade.
* Uses a reusable function for grading.
* Includes basic error handling.

---

## 📊 Grading System

|    Marks | Grade |
| -------: | :---: |
| 90 – 100 |   A   |
|  80 – 89 |   B   |
|  70 – 79 |   C   |
|  60 – 69 |   D   |
|   0 – 59 |   F   |
