# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Python, Pandas, and Matplotlib. It loads the dataset, cleans the data, performs sales analysis, creates visualizations, and provides meaningful business insights.

---

## Objectives

- Load sales data from a CSV file
- Clean and validate the dataset
- Perform sales analysis
- Generate charts
- Provide business insights

---

## Technologies Used

- Python
- Pandas
- Matplotlib
